# Mini Vegas Audio

Небольшой многодорожечный аудиоредактор в стиле Sony Vegas Pro на Python (PySide6 + numpy + ffmpeg).

## Установка (Linux, Debian/Ubuntu)

```bash
sudo apt install ffmpeg libportaudio2 libxcb-cursor0 python3-venv
cd audio_editor
./run.sh                 # создаст .venv, поставит зависимости и запустит
# или вручную:
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python main.py
```

Fedora: `sudo dnf install ffmpeg portaudio xcb-util-cursor`; Arch: `sudo pacman -S ffmpeg portaudio xcb-util-cursor`.

Файлы можно передать сразу при запуске: `./run.sh song.mp3 video.mp4`.

- `libportaudio2` нужен для `sounddevice` (воспроизведение). Без него редактор
  переключается на `ffplay` (входит в ffmpeg) в упрощённом режиме: правки во время
  воспроизведения не слышны до перезапуска.
- `libxcb-cursor0` нужен Qt 6.5+ для работы под X11/XWayland.
- Если `rubberband` есть в сборке ffmpeg, сдвиг тона делается им (качественнее), иначе через `asetrate + atempo`.

## Возможности

| Функция | Как |
|---|---|
| Импорт mp3 / ogg / wav / mp4 (и всего, что читает ffmpeg; из видео берётся звук) | Ctrl+I или перетащить файлы в окно |
| Сохранение / открытие проекта (`.mvproj`) | Ctrl+S / Ctrl+O |
| Пики (волна): пики и RMS по каждому каналу | строятся при импорте |
| Перемотка курсора | тянуть пунктир курсора или треугольник на линейке |
| Разрезать клип | курсор + **S** |
| Перемещение кусков (в т.ч. между дорожками), привязка к краям | перетащить мышью, **N** вкл/выкл привязку |
| Копирование клипа | **Ctrl + перетаскивание** (или Ctrl+C / Ctrl+V в позицию курсора) |
| Плавный переход (кроссфейд) | наложите клипы друг на друга на одной дорожке; вкл/выкл в меню «Вид» |
| Обрезка краёв, fade in/out | тянуть край клипа / квадратик в верхнем углу |
| Удаление | Delete; Ctrl+Delete — удалить выделенный диапазон со сдвигом |
| Пустой клип (тишина), например чтобы наложить на него шум | Ctrl+Shift+N |
| Несколько дорожек, громкость, панорама, Mute/Solo | заголовок дорожки, Ctrl+T — новая |
| Громкость / нормализация, тон и темп, реверберация, 10-полосный эквалайзер, шум, реверс | меню «Эффекты» (к выделенным клипам) |
| Менеджер активных эффектов: отключить, удалить, поменять порядок | Ctrl+Shift+F или правый клик по клипу |
| Каналы: разделить на Л/П, объединить два клипа в стерео, только левый/правый, поменять местами, моно | «Эффекты → Каналы» |
| Экспорт MP3 / OGG / WAV / MP4(AAC) / FLAC, любая частота, любой битрейт, моно/стерео, весь проект или диапазон | Ctrl+E |
| Отмена/повтор | Ctrl+Z / Ctrl+Y |

Пример «вырезать конец и поставить в начало»: поставьте курсор, нажмите **S**
(правая часть станет выделенной), отодвиньте основную часть вправо и перетащите
кусок в начало. Или Ctrl+X по куску, затем W и Ctrl+V.

Пример «убрать левый канал»: «Эффекты → Каналы → Только правый канал». Или
«Разделить на левый и правый»: появятся клипы [Л] и [П] на двух дорожках, лишний
можно удалить, обработать отдельно и потом выделить оба (Ctrl+клик) →
«Объединить два клипа в стерео».

Транспорт: Space — воспроизведение/стоп (курсор возвращается), Enter — пауза,
**W** (или Home) — в начало, Q — цикл по выделенному диапазону.
Масштаб: Ctrl+колесо, прокрутка по времени: Shift+колесо.
Однобуквенные клавиши работают и в русской раскладке (W = Ц, S = Ы, …).

Эффекты неразрушающие: клип хранит исходный звук и список эффектов, звук
пересчитывается при изменении списка. В файл проекта записываются ссылки на
исходные файлы (абсолютный и относительный путь) и списки эффектов. Звук, которого
нет ни в одном файле (результат «Объединить каналы»), сохраняется в папку
`<имя проекта>_media` рядом с проектом.

## Устройство

- `engine.py` — декодирование/кодирование через ffmpeg (сырой f32le по пайпам), модель проекта, микшер, пики, эффекты
- `player.py` — воспроизведение (sounddevice со сведением «на лету» или ffplay)
- `timeline.py` — линейка, дорожки, клипы, мышь, заголовки дорожек
- `dialogs.py` — экспорт и диалоги эффектов
- `main.py` — главное окно

Внутренняя частота проекта — 44100 Гц, стерео, float32; при экспорте ffmpeg ресемплирует в выбранную.
